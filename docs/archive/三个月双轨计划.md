# 3 个月双轨初步学习计划

> 目标不是“精通 Halcon/FOC”，而是 3 个月后能：
> 1. 用 Python + OpenCV 独立做一个视觉检测/定位小项目；
> 2. 说清 Halcon 的 Blob/标定/手眼流程，并跑通手眼标定数学；
> 3. 说清 FOC 电流环、EtherCAT PDO/CiA402、CSP/CSV/CST 的基本原理；
> 4. 从 GitHub 复刻一个机器人视觉项目，能改、能测、能讲。
>
> 每周 10–12 小时；每天 2 小时：40 分钟读/跑，40 分钟自己写，20 分钟记笔记。

## GitHub 复刻：旋转角检测

项目：<https://github.com/SasiriChathurika/rotation-angle-detection-for-pick-place-robots>（MIT）

```bash
git clone https://github.com/SasiriChathurika/rotation-angle-detection-for-pick-place-robots.git
cd rotation-angle-detection-for-pick-place-robots
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

原项目需要摄像头；本软件里的静态复刻版在：

```text
projects/github-rotation/main_static.py
projects/github-rotation/README.md
```

运行：

```powershell
runtime\Scripts\python.exe projects\github-rotation\main_static.py
```

预期：好匹配 180+、内点 170+、角度约 15°。

**复刻时要做的 3 件事**

1. 把全局变量改成函数参数；
2. 加 `inliers`、`angle`、匹配可视化；
3. 写清限制：没有相机标定、没有手眼、没有深度/传送带跟踪。

## 两个方向怎么选

| | Halcon + 手眼引导 | FOC / EtherCAT / 驱控一体 |
|---|---|---|
| 核心 | 视觉流程、标定、手眼、机器人接口 | 电流环、总线、伺服状态机、整定 |
| 入门硬件 | 相机 + 标定板 + 机械臂/滑台 | STM32 + 电机 + 编码器 + 驱动器 |
| 典型岗位 | 视觉应用开发、FAE、机器人集成 | 运动控制开发、伺服/驱动器、自动化 |
| 3 个月目标 | 能跑通一套 Pick 流程 | 能跑通电流环 + 一帧 EtherCAT |
| 先修 | Python/OpenCV、线性代数 | C 语言、电机学、控制基础 |

建议：**先都做一个小项目，再决定主攻**。视觉方向对 Python 友好，运动控制方向对 C/硬件更友好；两条线都懂的人在机器人集成岗位很吃香。
